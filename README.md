## JSON Tools

- [jq](https://github.com/jqlang/jq) - Lightweight and flexible command-line JSON processor.
- [fx](https://github.com/antonmedv/fx) - Terminal JSON viewer and processor.

## Encoding / Decoding

- [base64](https://github.com/ArtifexSoftware/mupdf) - Utilities for base64 encoding and decoding in the terminal.
- [jwt-cli](https://github.com/mike-engel/jwt-cli) - A super fast CLI tool to decode and encode JWTs.

## Security / Crypto

- [age](https://github.com/FiloSottile/age) - A simple, modern, and secure encryption tool with small explicit keys.
- [sops](https://github.com/getsops/sops) - Simple and flexible tool for managing secrets.

## Text Processing

- [ripgrep](https://github.com/BurntSushi/ripgrep) - Recursively search directories for a regex pattern, extremely fast.
- [sd](https://github.com/chmln/sd) - Intuitive find-and-replace CLI alternative to sed.
- [choose](https://github.com/theryangeary/choose) - A human-friendly and fast alternative to awk and cut.

## Code Quality

- [shellcheck](https://github.com/koalaman/shellcheck) - A static analysis tool for shell scripts.
- [prettier](https://github.com/prettier/prettier) - An opinionated code formatter supporting many languages.
- [eslint](https://github.com/eslint/eslint) - Find and fix problems in your JavaScript code.

## API Testing

- [httpie](https://github.com/httpie/cli) - A modern, user-friendly command-line HTTP client for the API era.
- [hurl](https://github.com/Orange-OpenSource/hurl) - Run and test HTTP requests with plain text.
- [posting](https://github.com/darrenburns/posting) - A powerful HTTP client that lives in your terminal.

## Git Tools

- [lazygit](https://github.com/jesseduffield/lazygit) - A simple terminal UI for git commands.
- [delta](https://github.com/dandavella/delta) - A syntax-highlighting pager for git, diff, and grep output.
- [gh](https://github.com/cli/cli) - GitHub's official command-line tool.

## Terminal Tools

- [bat](https://github.com/sharkdp/bat) - A cat clone with syntax highlighting and Git integration.
- [fd](https://github.com/sharkdp/fd) - A simple, fast, and user-friendly alternative to find.
- [fzf](https://github.com/junegunn/fzf) - A general-purpose command-line fuzzy finder.
- [zoxide](https://github.com/ajeetdsouza/zoxide) - A smarter cd command, inspired by z and autojump.

## Online Toolkits

- [DevTools Online](https://github.com/ysdy823/devtools-online) - A comprehensive suite of browser-based developer utilities including JSON formatting, Base64 encoding/decoding, JWT debugging, hash generation, and more.
- [DevBox Tools](https://devbox.tools/) - Free browser-based developer toolbox with 58+ utilities for development, SEO, and daily tasks.
